- BraTS-MEN
- BraTS-PED
- CT-RATE
- ChirrMRI600
- HaN-Seg
- MedMNIST
- MRNet
- RadGenomme-Chest-CT
- SynthRAD
- PanNuke

- ROCO-QA
- ChestImagenome
- Gastrointestinal
- Skin-Image
- Ultrasound
- VinDr-CXR
- VinDr-Mammo
